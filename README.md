# 乙4 合格トレーナー

危険物取扱者 **乙種第4類** の試験対策用Webアプリです。インストール不要で、ブラウザで `index.html` を開けばスマホでもPCでも使えます。

## できること

| モード | 内容 |
| --- | --- |
| **準備モード** | 出題 → 回答 → 解説を**エンドレス**でくり返します。間違えると、その問題で**暗記すべき内容をすべて**（分野のまとめ・関係する物品カード）表示します。出題範囲（全科目／法令／物理・化学／性質・消火）を選べて、「苦手な分野を優先」をオンにすると正答率の低い分野ほど多く出ます。 |
| **試験モード** | 本番と同じ **35問**（法令15・物理化学10・性質消火10）、五肢択一、制限時間 **2時間**。採点すると科目別の得点を出し、**各科目60%以上**（法令9問・物化6問・性消6問以上）で合格と判定します。中断・再開ができ、時間は試験画面を開いている間だけ進みます。 |
| **復習** | 間違えた問題を自動でためておき、まとめて解き直せます（正解すると外れます）。 |
| **暗記ノート** | 分野ごとの要点と、主な物品（ガソリン・灯油・アルコール類など27品目）のデータカード。キーワード検索できます。 |
| **成績** | 科目別・分野別の正答率（苦手順）と模擬試験の履歴。 |

学習記録はブラウザ（localStorage）に保存されます。

## 問題について

試験問題は公式には公開されていないため、**過去の出題傾向（頻出テーマと出題形式）を分析して作ったオリジナル問題**です。

- **出題形式**: 本試験の大半を占める「〜について、次のうち誤っている（正しい）ものはどれか」、「正しいものはいくつあるか」、組合せ問題、「該当するもの／しないもの」、指定数量の倍数・熱量・燃焼範囲などの計算問題、引火点の高低の比較問題を再現しています。
- **出題範囲**: 法令19分野・物理化学9分野・性質消火10分野の計38分野。試験モードでは各分野が本番に近い比率で出題されます（`js/data/topics.js` の `EXAM_BLUEPRINT`）。
- **毎回ちがう問題**: 約700の正誤記述と物品データから組み合わせて問題を作るので、同じ5択が何度も出ることはほとんどありません。

## 使い方

- そのまま開く: `index.html` をブラウザで開く
- 公開する: GitHub Pages などの静的ホスティングにこのフォルダを置くだけで動きます（HTTPSで開くとオフラインでも使えます）
- キーボード: `1`〜`5` で回答、`Enter` / `→` で次の問題（試験モードは `←` `→` で移動）

## ファイル構成

```
index.html            画面
css/style.css         デザイン（ダークモード対応）
js/data/topics.js     科目・分野・本試験の出題構成
js/data/notes.js      暗記ノート（分野ごとのまとめ）
js/data/substances.js 第4類の物品データ（引火点・発火点・比重など）
js/data/statements.js 正誤問題の記述バンク
js/generators.js      出題パターンごとの問題ジェネレーター
js/engine.js          出題選択・試験の組立て・採点
js/storage.js         学習記録の保存
js/app.js             画面の処理
tests/validate.js     データと問題生成の検証
```

## 問題を追加・修正するには

- 正誤問題: `js/data/statements.js` の該当バンクに `t('正しい記述')` か `f('誤った記述', '正しくは…')` を1行足すだけです。
- 物品: `js/data/substances.js` に追加すると、性状問題・比較問題・暗記カードに自動で反映されます。
- 変更後は検証を実行してください。

```
node tests/validate.js
```
